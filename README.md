# Surprise Random 2-Digit Number Generator

A simple web application that generates random 2-digit numbers from 00 to 99, 3-digit numbers from 000 to 999, 4-digit numbers from 0000 to 9999 with a chance to see a surprise number.

### Features

- Generates random 2-digit numbers (00-99), 3-digit numbers (000-999), and 4-digit numbers (0000-9999)
- Includes a surprise number feature
- Simple and intuitive user interface
- Instant generation on button click

### Usage

Click the "Generate Number" button to display a random 2-digit number, 3-digit number, or 4-digit number. Occasionally, a surprise number will appear!

### Getting Started

1. Clone the repository or download the source code
2. Open `index.html` in your web browser
3. Click the "Generate Number" button to start generating random numbers
