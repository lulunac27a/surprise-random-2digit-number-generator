# Surprise Random 2-Digit Number Generator

A simple web application that generates random 2-digit numbers from 00 to 99
with a chance to see a surprise number.

### Features

- Generates random 2-digit numbers (00-99)
- Includes a surprise number feature
- Simple and intuitive user interface
- Instant generation on button click

### Usage

Click the "Generate Number" button to display a random 2-digit number.
Occasionally, a surprise number will appear!

### Getting Started

1. Clone the repository or download the source code
2. Open `index.html` in your web browser
3. Click the "Generate Number" button to start generating random numbers
